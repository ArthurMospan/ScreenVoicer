# ScreenVoicer для Mac

Та сама програма, що й на Windows: знімок екрана → розмітка → голосовий коментар (розпізнається офлайн, прямо на Mac) → Markdown і картинка в буфері обміну. Вигляд і поведінка однакові на обох системах (див. [PARITY.md](../PARITY.md)).

Потрібен **macOS 14 Sonoma** або новіший. Найкраще працює на Mac з Apple Silicon (M1–M4): голос розпізнається на відеоядрі через Metal. На Intel теж працює, але повільніше.

## Встановлення (5 хвилин, один раз)

Програма безкоштовна і не має платного підпису Apple, тому macOS спершу її заблокує. Це нормально, ось як дозволити:

1. Завантажте **ScreenVoicer-macOS.dmg** (кнопка «Завантажити для Mac» на [sv.mospan.com.ua](https://sv.mospan.com.ua) або на сторінці [випусків](https://github.com/ArthurMospan/ScreenVoicer/releases); до 1.12.0 там був zip).
2. Відкрийте DMG: у вікні будуть **ScreenVoicer** і папка **Програми**. Перетягніть ScreenVoicer на «Програми» за стрілкою. (Із zip: відкрийте його й перетягніть **ScreenVoicer.app** у «Програми».)
3. Відкрийте ScreenVoicer з «Програм». macOS скаже, що не може перевірити програму. Натисніть **Готово** (не «Перемістити в кошик»).
4. Відкрийте  → **Системні параметри** → **Приватність і безпека**. Прокрутіть донизу, там буде рядок про ScreenVoicer. Натисніть **«Однаково відкрити» (Open Anyway)** і введіть пароль Mac.
5. Знову відкрийте ScreenVoicer і натисніть **Відкрити**.

Це потрібно лише один раз. Оновлення програма ставить сама, і macOS більше не питає.

> Якщо кнопки «Однаково відкрити» (Open Anyway) немає: відкрийте **Термінал** і вставте
> `xattr -dr com.apple.quarantine /Applications/ScreenVoicer.app`, потім відкрийте програму ще раз.

## Дозволи (при першому запуску)

ScreenVoicer покаже вікно «Дозволи для ScreenVoicer» і проведе по кроках:

- **Запис екрана**: щоб робити знімки. Натисніть «Дозволити» → увімкніть ScreenVoicer у списку «Запис екрана й системного аудіо» → натисніть «Перезапустити ScreenVoicer».
- **Мікрофон**: для голосового коментаря. Натисніть «Дозволити» у вікні macOS.

Раз на місяць macOS сама перепитує, чи дозволити й далі запис екрана. Просто натисніть «Дозволити». Дозволи зберігаються й після оновлень програми.

## Як користуватися

| Що | Як |
| :--- | :--- |
| Зробити знімок | **⌥⇧S** (Option + Shift + S) у будь-якій програмі, або **клік по іконці** в рядку меню |
| Меню | **правий клік** (або ⌃-клік) по іконці в рядку меню |
| Виділити область | потягніть мишею; **Enter** без виділення — весь екран |
| Підправити область | потягніть білий квадратик на куті чи стороні рамки |
| Голосовий коментар | затисніть **Пробіл** і говоріть, або коротко натисніть Пробіл / клацніть мікрофон |
| Зберегти й скопіювати | **Enter** — у буфері Markdown зі шляхом до PNG і коментарем, плюс сама картинка |
| Інструменти | **P** олівець, **H** маркер, **A** стрілка, **R** рамка, **T** текст, **N** мітки 1-2-3, **B** приховати (пароль, пошта), **E** гумка |
| Колір / товщина | **1–6**, **[** **]** |
| Скасувати / повторити | **⌘Z** / **⇧⌘Z** |
| Скасувати знімок | **Esc** |

Скриншоти лежать у `~/AI_Screenshots`, галерея відкривається з меню. Голос розпізнається тільки на вашому Mac і нікуди не надсилається.

## Чим відрізняється від Windows

Тільки тим, що вимагає сама macOS: гаряча клавіша ⌥⇧S замість Alt+Shift+S, іконка в рядку меню замість трею, дозволи «Запис екрана» і «Мікрофон», немає прискорення NVIDIA CUDA (на Mac голос рахує Metal). Повний список — у [PARITY.md](../PARITY.md).

## Якщо щось не працює

- **Знімок не робиться**: меню → «Про програму» → «Журнал», або перевірте дозвіл «Запис екрана» в Системних параметрах і перезапустіть програму.
- **Голос не розпізнається**: меню → «Мікрофон» → «Прослухати останній запис». Якщо тиша чи глухо — оберіть інший мікрофон.
- **Журнал**: `~/Library/Logs/ScreenVoicer/screenvoicer.log`. Налаштування, історія і моделі: `~/Library/Application Support/ScreenVoicer/`.

## Для розробника

Swift 5.9+ / SwiftUI + AppKit, без Xcode-проєкту:

```sh
mac/scripts/build.sh            # ScreenVoicer.app + ScreenVoicer-macOS.zip у mac/build/
mac/build/ScreenVoicer.app/Contents/MacOS/ScreenVoicer --selftest --wav speech.wav --expect test
mac/build/ScreenVoicer.app/Contents/MacOS/ScreenVoicer --snapshots out/   # PNG кожного вікна
mac/build/ScreenVoicer.app/Contents/MacOS/ScreenVoicer --ui-test out/     # справжні вікна + синтетичні миша й клавіші
```

- Розпізнавання: [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (готовий xcframework з Metal, SHA-256 перевіряється в `build.sh`), ті самі моделі й параметри, що у Windows-версії.
- Підпис: кожна збірка підписується тим самим самопідписаним сертифікатом (секрети `MAC_CERT_P12` / `MAC_CERT_PASSWORD`), тому macOS не забуває дозволи після оновлення. CI перевіряє, що вимога підпису не змінилася.
- Оновлення: як у Windows, через GitHub Releases (`ScreenVoicer-macOS.zip`, SHA-256), плюс перевірка, що оновлення підписане тим самим сертифікатом.
- Де що лежить: `Core/` — двійники `Services/*.cs`, `Overlay/` — `Views/OverlayWindow`, `UI/` — меню, галерея, сповіщення, діалоги; кольори й іконки — `UI/Theme.swift` і `UI/Icons.swift` (ті самі значення й path-дані, що в `App.xaml`).
